# LiveMap — интерактивная карта России с публичными камерами

## Идея проекта

Создать масштабируемую интерактивную карту России, на которой размещены объекты с доступными видеокамерами. Пользователь перемещается по карте, приближает нужный регион, выбирает объект — например, улицу, перекрёсток, площадь, парк, вокзал или другое публичное место — и смотрит камеры, привязанные к нему.

В проекте используются только бесплатные публичные трансляции, тестовые камеры либо потоки, на использование которых есть разрешение. Приватные камеры, платные сервисы и обход ограничений доступа не входят в задачу.

## Что должно уметь приложение

- Показывать карту России с возможностью приближения, отдаления и перемещения.
- Отображать на карте объекты, у которых есть одна или несколько камер.
- Объединять большое количество маркеров в кластеры на малом масштабе.
- Загружать объекты только для видимой области карты (`bounding box`).
- Открывать карточку выбранного объекта: название, адрес, координаты и камеры.
- Показывать список доступных камер выбранного места.
- Воспроизводить видеопоток выбранной камеры прямо в браузере.
- Позволять администратору добавлять и редактировать объекты и камеры через API.

## Пользовательский сценарий

1. Пользователь открывает карту России.
2. На общем масштабе он видит кластеры камер и объектов.
3. При приближении появляются отдельные точки: улицы, перекрёстки, площади и другие места.
4. Пользователь нажимает на интересующий объект.
5. Открывается карточка объекта со списком доступных камер.
6. Пользователь выбирает камеру.
7. В модальном окне или боковой панели запускается трансляция.

## Текущее состояние

Есть интерактивная карта России на MapLibre, поиск по опубликованному каталогу, карточка места с плеером и административный интерфейс. Подложка по умолчанию — OpenFreeMap. `VITE_MAPTILER_KEY` включает поиск внешних адресов и населённых пунктов через MapTiler Geocoding; `VITE_MAP_STYLE_URL` задаёт пользовательскую подложку. MapTiler Streets проверен для российских городов, но на крупном масштабе показал английские подписи, поэтому не включён по умолчанию. В локальном каталоге опубликованы восемь проверенных эфиров в Петербурге, Астрахани и Кабардино-Балкарии. RUTUBE ограничил встраивание новосибирского эфира на стороннем сайте: worker отмечает его недоступным, а карта скрывает маркер по умолчанию; переключатель «Все камеры» показывает недоступные точки серым цветом. История проверки и процедура публикации записаны в [реестре live-источников](docs/live-sources.md). Для RTSP выбран [план медиашлюза](docs/media-gateway.md); production-развёртывание относится к следующим этапам. Критерии релиза записаны в [границах продукта](docs/product.md), решения по компонентам и поставщикам — в [архитектуре](docs/architecture.md), маршруты и форматы — в [контракте API](docs/api.md).

## Локальный запуск API

1. Скопируйте `.env.example` в `.env` и задайте пароль базы данных. Порт `54322` выбран для Docker-базы LiveMap, чтобы не конфликтовать с локальным PostgreSQL на `5432`.
2. Запустите Docker Desktop и выполните `docker compose up -d db`.
3. Выполните `uv sync` и `uv run alembic upgrade head`.
4. Создайте первого администратора: `uv run livemap-admin create-user USERNAME --role admin`. Пароль вводится интерактивно.
5. Запустите `uv run livemap` и откройте `http://127.0.0.1:8000/docs`.
6. Добавьте исследованные камеры как неопубликованные черновики: `uv run livemap-seed-candidates`. Для публикации восьми проверенных эфиров выполните `uv run livemap-seed-verified`, пока даты браузерных проверок в реестре моложе семи дней. Запустите проверку камер отдельным процессом: `uv run livemap-worker`. Остальные источники остаются кандидатами до подтверждения условий и воспроизведения с домена LiveMap.
7. В `frontend/` выполните `npm ci` и `npm run dev`. Карта доступна на `http://localhost:5173/`, карточка места — на `/place/ID`, админ-интерфейс — на `/admin`. Опциональный `VITE_MAPTILER_KEY` задайте в `frontend/.env.local`, затем перезапустите Vite. Без ключа работает карта OpenFreeMap и поиск по собственному каталогу; внешнее геокодирование отключено.

`/api/v1/health/live` подтверждает работу приложения. `/api/v1/health/ready` дополнительно проверяет БД и возвращает 503, если она недоступна. `GET /api/v1/places`, `/places/search` и `/places/{id}` доступны без входа; остальные операции каталога используют Bearer-токен из `POST /api/v1/admin/login`.

Для первого импорта откройте [`demo/places.geojson`](demo/places.geojson) и передайте его содержимое в `/api/v1/admin/import/preview`, затем в `/apply`. Эти места остаются черновиками и не появляются на публичной карте без разрешённых работающих камер.

`uv run pytest` запускает и интеграционные тесты: они создают временную отдельную БД в работающем PostGIS, проверяют миграцию и откат, затем удаляют тестовую БД. `uv run alembic check` сравнивает модели с миграциями. Compose хранит данные LiveMap в отдельном томе `livemap_pgdata`.

Правила одобрения камер, проверки HLS/iframe, ограничения worker и порядок удаления описаны в [эксплуатации камер](docs/camera-operations.md). Сейчас повторной публикации подлежат восемь проверенных эфиров; остальные кандидаты остаются скрытыми до подтверждения условий и доступности.
