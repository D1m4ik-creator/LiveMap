## Ограничения этого окружения

Обычный Git не подключается к proxy:8080; отправка выполнена через GitHub
Git Data API с fast-forward refs. Прямой smoke с Render завершился ошибкой
сетевого доступа Operation not permitted; внешнюю проверку выполняет GitHub
Actions. Нет настроенных PostgreSQL credentials, pg_dump, age или recovery
identity для настоящего архива. Render запросил подтверждение workspace
OpenSorse; ответа пока нет. Изменения относятся к служебным скриптам,
workflow и документации, поэтому деплой приложения и миграция БД не нужны.

Невыполненные карточки не отмечены завершёнными.
