# LiveMap: интерфейс карты

## Идея

Карта остаётся главным полотном, а управление выглядит как лёгкие плавающие панели. Собственный знак эфира, бирюзовые маркеры, коралловый пульс и тёплая светлая подложка отличают LiveMap от поставщика карт. Карточка камеры всегда показывает владельца потока и время проверки.

## Макеты

### Desktop: от 1101 px

```text
┌─ логотип ───── поиск города, улицы или места ───── эфир ─ админка ┐
│ слои · только в эфире / все камеры · категория                    │
│ ┌─ карточка места / приветствие ─┐                     + −       │
│ │ название, адрес, координаты    │       КАРТА         гео тема  │
│ │ камеры и состояния             │       маркеры                  │
│ │ выбранный видеоплеер           │       кластеры                 │
│ └────────────────────────────────┘                     атрибуция │
└──────────────────────────────────────────────────────────────────┘
```

Карточка закреплена слева, занимает до 390 px и прокручивается независимо от карты. Поиск расположен в верхней панели. Выбранный маркер выделяется коралловым кольцом.

### Tablet: 761–1100 px

```text
┌─ логотип ─── поиск ─── действия ┐
│ слои · категория                │
│ ┌─ карточка 350 px ─┐  КАРТА    │
│ │ место / камеры    │  маркеры  │
│ └───────────────────┘           │
└─────────────────────────────────┘
```

Карточка становится уже; карта сохраняет управление и атрибуцию. Админ-формы располагаются в двух колонках, пока для них хватает ширины.

### Mobile: до 760 px

```text
┌─ знак ─── поиск ─── меню ┐
│ эфир · категория         │
│       КАРТА       + −   │
│       маркеры      гео  │
│                    тема │
├─────────────────────────┤
│ нижняя панель места     │
│ камеры → видеоплеер     │
└─────────────────────────┘
```

Карта рисуется в свободной верхней области экрана. Нижняя панель занимает не более 51% высоты, поэтому жесты карты не перехватываются панелью. Кнопки управления картой и меню имеют цель касания 44×44 px. Для малого экрана стартовый масштаб охватывает Россию целиком.

В горизонтальном положении телефона карта занимает весь экран, карточка места превращается в прокручиваемую панель слева, управление картой размещается справа в две колонки. Начальный обзор России пересчитывается при повороте; при ширине видимой карты больше 360° API получает всю долготу, чтобы маркеры не пропали из-за перехода через меридиан.

## Токены

| Назначение | Светлая тема | Тёмная тема |
| --- | --- | --- |
| Фон | `#F5F3EE` | `#0D1C20` |
| Поверхность | `#FFFDF9` | `#14262A` |
| Основной текст | `#17252C` | `#EFF6F4` |
| Вторичный текст | `#5C6F76` | `#A3B6B7` |
| Маркер и декоративный акцент | `#00A99D` | `#00A99D` |
| Акцент в тексте и кнопках | `#00776F` | `#5FE1CB` |
| Индикатор LIVE | `#FF6B57` | `#FF6B57` |

Manrope используется для заголовков и интерфейса с запасным Arial. Основной ритм отступов строится от 8 px; крупные области используют шаги 16 и 24 px. Панели имеют радиусы 12–20 px, небольшие элементы — 8–10 px. У каждого интерактивного элемента есть видимый фокус, анимация сокращается при `prefers-reduced-motion`.

Значения цветов, шагов и радиусов хранятся в [`frontend/src/ui/tokens.css`](../frontend/src/ui/tokens.css). Компоненты интерфейса в `frontend/src/ui`: `ActionButton` с вариантами primary/secondary/danger, `FormField` для связанного с полем заголовка и подсказки, `TabBar` для навигации, `StatusBadge` для состояния камеры, `SkeletonStack` для загрузки карточки. Поиск (`SearchBox`) и карточка камеры (`CameraCard`) остаются в предметных модулях и используют те же токены. Иконки берутся из Lucide; для декоративных иконок указан `aria-hidden`, а кнопки без текста имеют `aria-label`. Для кнопок и полей определены hover, focus и disabled состояния.

Контраст проверен для обычного текста: `#00776F` на `#FFFDF9` — 5.34:1, на `#E7F8F5` — 4.95:1; `#5C6F76` на `#FFFDF9` — 5.18:1; `#5FE1CB` на `#14262A` — 9.79:1. Яркий `#00A99D` оставлен для маркеров и декоративных элементов, а текстовые акценты затемнены.

## Компоненты и состояния

- Верхний поиск показывает загрузку, подсказки и пустой результат. Стрелки и Enter выбирают подсказку, Escape закрывает список.
- MapLibre показывает серверные точки и кластеры; кластер приближает карту, точка открывает карточку. По умолчанию видны только проверенные работающие камеры. Переключатель «Все камеры» добавляет недоступные точки серым цветом; список точек сообщает «Нет эфира». Ошибка подложки и ошибка данных выводятся отдельно с кнопкой повтора.
- Карточка места показывает адрес, координаты, камеры, источник и время проверки. Недоступная камера имеет отдельный цвет и не раскрывает URL воспроизведения.
- Плеер загружается только после выбора камеры. Для HLS есть mute и повтор, для iframe используются элементы управления поставщика; ссылка на первоисточник остаётся видимой.
- Админка отделена от публичной карты, хранит токен только в памяти страницы и показывает результат операций, импорт с предпросмотром и журнал изменений.
- В редакторе камеры отображаются публикация и фактический статус эфира отдельно, формальные препятствия для публикации и последние десять проверок worker. Предпросмотр импорта можно выполнить без записи в каталог.
- Для экранного диктора есть список точек как альтернатива маркерам на canvas; группы различаются координатами. При открытии карточки фокус переходит на заголовок. Режим уменьшения анимации отключает также перелёты MapLibre.
