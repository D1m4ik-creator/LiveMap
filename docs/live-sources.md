# Стартовые live-источники

Проверка выполнена 26 сентября 2026 года. [Справка RUTUBE](https://rutube.ru/info/embed/) разрешает встраивать открытые трансляции на сторонние сайты через официальный iframe-плеер. LiveMap показывает этот плеер без копирования видео и указывает канал в карточке. При отзыве публичного доступа, жалобе правообладателя или изменении правил источник снимается с публикации.

HTTP-ответы обоих iframe были `200` без блокирующих `X-Frame-Options` и `frame-ancestors`. Эфир Дворцового моста дополнительно воспроизведён во вложенном плеере локального LiveMap: `readyState=4`, кадр 1280×720, время видео увеличивалось. Это проверка на указанную дату, а не гарантия непрерывной работы или доступности на будущем публичном домене.

Контакт платформы для удаления: `help@rutube.ru`. Право платформы на встраивание не даёт права скачивать, перезаписывать или транслировать видео через собственный сервер. Остальные кандидаты в `demo/camera_candidates.json` остаются скрытыми до отдельного подтверждения условий.

## Воспроизводимая публикация

1. После миграций выполните `uv run livemap-seed-candidates`: записи появятся как неопубликованные черновики.
2. Пока дата браузерной проверки в реестре моложе семи дней, выполните `uv run livemap-seed-verified`. Команда сверяет данные с проверенным реестром, делает сетевую проверку эфира, публикует только две отмеченные записи и пишет аудит. Повторный запуск не продлевает дату проверки и не возвращает снятую с публикации камеру.
3. Запустите `uv run livemap-worker` для периодического контроля. Для повторного включения после жалобы или истечения проверки администратор должен заново проверить источник и iframe через админ API.

Worker для RUTUBE сверяет наличие публичного live HLS в официальном API и не считает один лишь ответ iframe `200` доказательством работающего эфира. Проверка реальных кадров остаётся ручной: сайт плеера может открыть оболочку, даже если видео не воспроизводится.
