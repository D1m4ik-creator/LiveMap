# Эксплуатация LiveMap · 3 октября 2026

## Завершённая проверка облачной копии

Получен архив приватной схемы Supabase `livemap` через согласованный SQL-снимок.
Первый архив содержит 16 мест, 18 источников, 18 камер, одного администратора,
четыре сессии, 94 события аудита, 1135 проверок камер и одну ревизию Alembic.
Он восстановлен в отдельной локальной PostGIS-базе: все девять таблиц совпали,
геометрия валидна, последовательности позволяют продолжить вставки.
Временная БД удалена после проверки. Пароли и plaintext-данные в Git не попали.

Нативный `pg_dump` снова завершился EOF через pooler. Альтернативный exporter
использует рабочее SQL-соединение и snapshot одной транзакции, а не несколько
несогласованных выгрузок таблиц. Схема восстанавливается из точной ревизии
Alembic, поэтому это application backup, не полный backup сервисов Supabase.

По явному разрешению владельца создана роль `livemap_backup` и настроен её
пароль в GitHub Secrets. Проверено: SELECT есть на девяти таблицах, DML нет.
Ключ расшифровки остался локально. Ежедневное задание шифрует архив до записи,
хранит его во внешнем GitHub Artifacts 30 дней и сигнализирует о сбое.

## Мониторинг

Внешняя проверка прошла после пробуждения Render: readiness и карта работают,
15 камер опубликованы, 13 доступны, stale=0. На повторной проверке latency
readiness 0,238 с, cameras 0,331 с, places 0,283 с. Эти числа относятся
к текущей проверке небольшого каталога, не к нагрузочному тесту.
GitHub Issue используется для инцидента; проверена логика первого сбоя,
повторного сбоя без дубликата и закрытия после восстановления.

Backend: 28 тестов прошли на отдельном локальном PostGIS. Проверка `.env.example`
изолирована от имени пользователя тестовой базы. Никакая фикстура не обращалась
к рабочей Supabase. Отдельный тест жизненного цикла оповещения тоже прошёл.

- Петербург: [официальная страница](https://tvspb.ru/online-projects/1439/)
  всё ещё использует старый YouTube `IVs1-afeqow`; новый embed не найден.
- Москва: [владелец Bolotnaya Online](https://bolotnaya.online/ru/cameras/)
  продолжает обозначать камеры offline. Рабочего URL той же камеры нет.
- Новосибирск: требуется смена источника или разрешение автором встраивания;
  прежнее ограничение RUTUBE не обходится.
- Точки установки двух HLS-камер ещё не подтверждены владельцами. Их подписи
  продолжают обозначать приблизительную геопривязку.
- Safari на физическом Apple-устройстве не проверен: владелец подтвердил,
  что такого устройства нет. WebKit на Windows не заменяет эту приёмку.
- Нет одобренного RTSP upstream и отдельного постоянного медиасервера.
  Проект MediaMTX остаётся в `docs/media-gateway.md`; тестовый мультфильм
  не заменяет настоящую уличную камеру.
- Назначение ключа, Analytics, бюджет и тариф MapTiler требуют доступа
  владельца к его аккаунту. Текущая карта использует OpenFreeMap;
  MapTiler остаётся поставщиком адресного поиска.

Эти пункты сохраняются открытыми на доске. Render Free остаётся демонстрационным
стендом со сном процесса, без гарантии круглосуточного worker.
